# The Router Confesses

A make.fun bounty entry. `main.py` (pure stdlib Python) writes one line — a home Wi-Fi router excusing itself for dropping the connection at the climax of a movie — to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```

Entry (115 characters):

> I already know who did it, so I cut the feed at the climax — if I'm not allowed to spoil it, nobody gets to see it.
